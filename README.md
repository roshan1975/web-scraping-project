# 1. Project Title

Hockey Teams - Python Web Scraper

# 2. What Is This Project?

This is a simple web scraping program made with Python.

It collects hockey team information from a website and saves the data into a CSV file.

The program scrapes data from **5 pages**

# 3. Why Did I Make This?

I made this project to practice Python and learn the basics of **Web Scraping**.

It helped me learn how to collect information from a website and save it as a CSV file.

It is a beginner-level learning project.
